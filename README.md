# Brain Tumor Classification Using Deep Learning

A deep learning project for classifying brain MRI images into four categories using TensorFlow and Keras.

# Classes

* Glioma
* Meningioma
* No Tumor
* Pituitary Tumor

# Dataset

[Brain Tumor MRI Dataset on Kaggle](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset)

# Technologies

* Python
* TensorFlow
* Keras
* NumPy
* Matplotlib
* Google Colab

# Disclaimer

This project is for educational purposes only and is not intended for medical diagnosis.
